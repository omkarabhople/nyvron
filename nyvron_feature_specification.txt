FEATURE 1: THE CONTEXTUAL KNOWLEDGE GRAPH (BIDIRECTIONAL LINKING)
- Visual Interface (Ref: watermarked_img_5098760068325598459.png): 
  Materializes inside the `tab-ai` slide-out panel labeled AI ASSISTANT. When active, 
  it renders an interactive node-and-edge network map. The central focus node represents 
  the active document ("Comprehensive Conservation Report"). Radiating outward are 
  connected peripheral nodes such as "Project Strategy", "Wildlife Zones", "Q3 Review", 
  and "Zonal Mapping Notes".
- The Action Workflow: 
  When a user hovers or clicks a sub-node like "Wildlife Zones" using the cursor, the 
  connection paths dynamically highlight. Text in any note or journal can reference 
  these nodes using simple Markdown wiki-links (e.g., [[Wildlife Zones]] or 
  [[Comprehensive Conservation Report#Page 16]]).
- AI Backend Logic: 
  The local LLM parses user text inputs for [[...]] syntax strings. It registers these 
  strings into an internal graph database (using a client-side library like Vis.js or 
  Cytoscape.js mapped over IndexedDB storage). Clicking a node triggers a router event 
  that passes the specific URI coordinates, causing the main reader window to jump 
  immediately to the precise page and element snippet ID.

FEATURE 2: "AMBIENT SMART CAPTURE" & AI MICRO-JOURNALING
- Visual Interface (Ref: watermarked_img_13655519118830762370.png): 
  The document toolbar natively houses an interactive microphone button component 
  (<button class="mic-capture-btn">) next to the font size and bookmark settings. 
  In the DOM inspector panel on the right, this links directly to the specialized DOM 
  node structural layouts: <div class="micro-journal-container"> and 
  <div class="journal-smart-capture" class="smart-capture-container">.
- The Action Workflow: 
  While reviewing page 16 of a dense report, the user taps the mic button. They dictate 
  a spoken note ("This tiger reserve list connects to the project strategy from yesterday"). 
  The container expands into an active state, capturing local device hardware audio.
- AI Backend Logic: 
  The captured audio snippet is routed instantly to a streaming local Automatic Speech 
  Recognition (ASR) engine (such as Whisper-base running client-side via WebGPU). The 
  transcribed string is automatically injected with metadata parameters capturing the 
  parent context: { documentId: "Comprehensive_Conservation...", page: 16, timestamp: 
  Date.now() }. The processed node appending occurs straight into the section 
  id="tab-journal" component.

FEATURE 3: INFINITE MARGIN CANVAS (FREEFORM ANNOTATION LAYER)
- Visual Interface (Ref: watermarked_img_13655519118830762370.png): 
  The tool array directly above the reading plane exposes pen, highlighter, eraser, and 
  vector shape selectors. The workspace container encapsulates a transparent, vector-based 
  HTML5 canvas overlay or absolute SVG viewport layer that spans fluidly beyond the 
  document boundaries.
- The Action Workflow: 
  Users draw structural flowcharts, sketch conceptual diagrams, or position rich-text 
  sticky notes inside the margins alongside the official PDF layouts.
- AI Backend Logic: 
  Rather than calculating pixel positioning fixed relative to the screen frame window, 
  vector coordinates are calculated relative to bounding client rectangles of individual 
  text paragraph tokens (DOMRect). If the screen scales, switches orientations, or shifts 
  responsively (e.g., matching the Dimensions: Responsive - 400 x 714 layout), the canvas 
  vectors realign dynamically via Matrix translation calculations, ensuring margin 
  annotations stay anchored alongside their corresponding paragraphs.

FEATURE 4: SPACED REPETITION & AUTO-FLASHCARD GENERATION
- Visual Interface (Ref: watermarked_img_13655519118830762370.png): 
  This feature bridges background parsing utilities directly with the DOM panel section 
  classified as <section id="tab-calendar" class="tab">.
- The Action Workflow: 
  When textual selections are highlighted or committed to the journal sub-components, 
  flashcard notifications appear unobtrusively within the workspace layout, offering 
  customized flashcard pairings.
- AI Backend Logic: 
  As content selections are saved, a background worker feeds the strings to an extraction 
  model prompt ("Extract the core facts/definitions from this text and format as a concise 
  Q&A flashcard card pair"). The output is written to a local card repository database. 
  Review triggers are calculated using an SuperMemo SM-2 algorithmic variant. When the 
  milestone date hits, flashcard prompts automatically generate an alert window node inside 
  the main workspace on app startup.

FEATURE 6: TIME-TRAVEL READING LOG (THE CALENDAR VIEW)

FEATURE 7: GLOBAL SEMANTIC SEARCH
- Visual Interface (Ref: watermarked_img_5098760068325598459.png): 
  Positioned inside the header boundary of the AI ASSISTANT panel, a global text input 
  component is initialized with a placeholder string reading <input placeholder="Search the graph...">.
- The Action Workflow: 
  Instead of typifying strict string queries, users type natural, conceptual prompts, such as 
  "Show me everything related to environmental conservation policy impacts in western India."
- AI Backend Logic: 
  Text blocks across books, margins, and flashcards are chunked and transformed into

  conceptual relevance, skipping keyword dependence entirely.
